# Map outline source

countries.geojson is Natural Earth's ne_110m_admin_0_countries dataset.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Natural Earth: https://www.naturalearthdata.com/
Terms: https://www.naturalearthdata.com/about/terms-of-use/

Natural Earth data is public domain. The preview uses a small-scale simplified outline map, not a navigation or live-location service. It makes no external tile requests and requires no map API key. Map text, markers and UI are rendered separately in Flutter.
