# Closer branding

Peach and coral embracing shapes form a heart, paired with a lowercase terracotta wordmark on warm ivory.

- `closer-app-icon.png`: 1024px launcher master, opaque square.
- `closer-logo.png`: horizontal wordmark on ivory.

Created using the built-in OpenAI image generation tool. These are design assets, not runtime Meta API outputs.

Icon prompt: Create one opaque square mobile launcher icon for Closer on warm ivory #FFF9F0, with two interlocking rounded C-shaped ribbons in apricot #F6B59B and coral-peach #F18F77 embracing around a heart-shaped negative space. Minimal smooth forms, muted terracotta overlap, readable at small sizes, no text or mockup.

Logo prompt: Preserve the icon's embracing heart symbol on the left and add the exact lowercase word 'closer' on the right, in warm terracotta #B96450 and friendly rounded medium-bold sans-serif. Wide layout, clean warm ivory background, generous clear space, no tagline or mockup.

Android, iOS, macOS and web PNG launcher assets are resized from the icon master. Rebuild and reinstall the mobile app to refresh its launcher icon.
