# Closer password reset email

The reset screen sends a standard Firebase Authentication password-reset request. The email’s sender and template are configured in Firebase Console, not in Flutter.

In Firebase Console, open **Authentication → Templates → Password reset → Edit** and use:

- **Sender name:** Closer
- **Sender local part:** `no-reply`
- **Subject:** Reset your Closer password
- **Reply-to:** `joshuachristianmirang@gmail.com`
- **Message:**

```text
Hello,

We received a request to reset the password for your Closer account (%EMAIL%).

Use this secure link to choose a new password:
%LINK%

If you did not request this change, you can ignore this email. Your password will not change unless the link is used.

Take care,
The Closer team
```

A branded sender display name and message can be set in the template. For the actual From address to use a Closer-owned domain (for example, `no-reply@closer.example`), first own that domain and verify/apply it in the template’s **Customize domain** flow by adding the DNS records Firebase provides. Firebase documents this setup at https://firebase.google.com/docs/auth/email-custom-domain. The message links can also use a verified custom domain.

The password-reset link is generated by Firebase and contains a one-time action code and project identifiers. Do not paste a live reset email or link into public chats, screenshots, issue trackers, or source control.
