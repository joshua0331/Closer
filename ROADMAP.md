# Closer roadmap

Updated October 31, 2026. Implementation and live validation are separate milestones.

## Connected foundation

- [x] Closer peach branding, app icon and native identifiers `com.jcm.closer`.
- [x] Real Firebase email/password sign-in, sign-out and password reset.
- [x] One-time, expiring partner invitations and persistent pairing.
- [x] Authenticated shared chat, photos, replies, reactions and memories.
- [x] Private Cloud Storage media served after couple-membership authorization.
- [x] Real interactive street map with attribution and tile caching.
- [x] Opt-in GPS sharing, last-update labels, distance and location removal.
- [x] Verified deployed cross-account data sharing and outsider rejection using synthetic accounts.

## Shared court and Meta AI

- [x] Shared summons and two-person entry from separate accounts.
- [x] Server-controlled speaking roles, two-minute deadlines and stale-write rejection.
- [x] Evidence, openings, cross-examination, rebuttals and judge questions.
- [x] Spark first ruling; Wonder single appeal with the prior record.
- [x] Separate approvals and accepted/unresolved shared closure.
- [x] Per-participant consented portraits and shared Muse Image artwork integration.
- [x] Optional SAM object boxes with original-photo access.
- [x] Live Spark and Wonder verification using a fictional case.
- [ ] Live Muse Image and SAM image-quality/geometry verification.
- [ ] Full hearing/appeal/portrait walkthrough on two physical phones.

## Release readiness

- [x] Hosted backend, private Meta secret, expiring AI demo sessions and persistent quotas.
- [x] Per-account shared-data/upload limits.
- [x] Build the connected Android debug APK.
- [ ] Verify gallery/GPS and paired UI on physical devices.
- [ ] Build/sign/test iOS on a Mac and iPhone.
- [ ] Push notifications for messages and summons; actual read acknowledgments.
- [ ] Pagination beyond the latest 150 records.
- [ ] Unpairing, account/data deletion/export and retention controls.
- [ ] Broader abuse controls, privacy review and production operating limits.
- [ ] Accessibility, interrupted-upload and offline recovery testing.
- [ ] Three-minute demo video, public setup verification and asset/contribution disclosures.

Background location tracking is intentionally outside the current foreground-sharing implementation. Budget/rate controls are not a financial spending cap. See [connected-app.md](docs/connected-app.md) for current behavior and verification boundaries.
